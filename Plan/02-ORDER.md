# งานที่ 2: ระบบจัดการออเดอร์

## ผู้รับผิดชอบ

สมาชิกคนที่ 2

## เป้าหมาย

พัฒนาส่วนจัดการรายการสั่งซื้อที่เชื่อมกับลูกค้า สามารถสร้างข้อมูลจำลอง 20-30 รายการ แสดง แก้ไขจำนวนกล่อง ลบรายรายการ ล้างรายการจำลองทั้งหมด และค้นหาออเดอร์ในรัศมี 2 กิโลเมตรจากพิกัดที่กำหนด

## ข้อมูลออเดอร์

- `id`: รหัสออเดอร์
- `orderCode`: รหัสออเดอร์ที่แสดงให้ผู้ใช้
- `customerId`: ลูกค้าที่สั่งซื้อ
- `customer`: ข้อมูลลูกค้าที่ join มาแสดง
- `boxQuantity`: จำนวนกล่อง 1-3 กล่อง
- `status`: `pending`, `assigned`, `delivered` หรือ `cancelled`
- `deliveryDate`: วันที่จัดส่ง
- `isSimulated`: ระบุว่าเป็นข้อมูลจำลอง
- `createdAt`, `updatedAt`: วันเวลาสร้างและแก้ไข

## Backend API ที่ต้องทำ

| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | `/api/orders` | แสดงออเดอร์ทั้งหมดพร้อมข้อมูลลูกค้า |
| GET | `/api/orders/:id` | แสดงออเดอร์ตาม ID |
| POST | `/api/orders` | เพิ่มออเดอร์ |
| PUT | `/api/orders/:id` | แก้ไขจำนวนกล่องหรือข้อมูลที่อนุญาต |
| DELETE | `/api/orders/:id` | ลบออเดอร์หนึ่งรายการ |
| POST | `/api/orders/simulate` | สร้างออเดอร์จำลอง 20-30 รายการ |
| DELETE | `/api/orders/simulated` | ลบออเดอร์จำลองทั้งหมด |
| GET | `/api/orders/nearby?latitude=16.245&longitude=103.25&radiusKm=2` | ค้นหาออเดอร์ในรัศมี 2 กม. |

## กฎและ Validation

- `customerId` ต้องมีอยู่จริงในตารางลูกค้า
- จำนวนกล่องต้องเป็นจำนวนเต็ม 1-3 กล่องต่อออเดอร์
- ออเดอร์จำลองทุกตัวต้องมีลูกค้า จำนวนกล่อง และวันที่จัดส่งครบถ้วน
- การล้างข้อมูลจำลองต้องลบเฉพาะรายการที่ `isSimulated = true`
- การล้างออเดอร์ต้องไม่ลบข้อมูลลูกค้า
- การค้นหาระยะทางต้องใช้พิกัดของลูกค้าที่เชื่อมกับออเดอร์
- ควรป้องกัน endpoint ล้างข้อมูลใน production

## Frontend ที่ต้องทำ

1. สร้าง `OrderService` และ `Order` model
2. แสดงออเดอร์พร้อมชื่อและตำแหน่งลูกค้า
3. สร้างฟอร์มเพิ่มและแก้ไขจำนวนกล่อง
4. เพิ่มปุ่มสร้างออเดอร์จำลอง 20-30 รายการ
5. เพิ่มปุ่มล้างออเดอร์จำลองพร้อมยืนยันอีกครั้ง
6. แสดงจำนวนออเดอร์และจำนวนกล่องรวม
7. เพิ่มตัวกรองออเดอร์ในรัศมี 2 กิโลเมตร
8. ส่งรายการออเดอร์ที่ผ่านการตรวจสอบแล้วให้ส่วนคำนวณเส้นทาง

## งานที่ต้องส่งมอบ

- migration หรือ schema ตาราง `orders`
- seed หรือ simulation script ที่สร้างออเดอร์ครบถ้วน 20-30 รายการ
- Order API พร้อม validation
- Angular service และหน้าจอจัดการออเดอร์
- ทดสอบการเพิ่ม แก้ไข ลบ จำลอง ล้าง และค้นหาระยะ 2 กม.
