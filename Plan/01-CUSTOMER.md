# งานที่ 1: ระบบจัดการลูกค้า

## ผู้รับผิดชอบ

สมาชิกคนที่ 1

## เป้าหมาย

พัฒนาส่วนจัดการข้อมูลลูกค้าให้เจ้าของร้านสามารถเพิ่ม แก้ไข ลบ แสดงผล ค้นหาจากชื่อหรือนามสกุล และค้นหาลูกค้าภายในรัศมี 1 กิโลเมตรจากพิกัดที่กำหนด

## ข้อมูลลูกค้า

ข้อมูลขั้นต่ำที่ต้องมี:

- `id`: รหัสลูกค้า
- `firstName`: ชื่อ
- `lastName`: นามสกุล
- `phone`: เบอร์โทรศัพท์
- `latitude`: ละติจูด
- `longitude`: ลองจิจูด
- `address`: รายละเอียดที่อยู่
- `createdAt`, `updatedAt`: วันเวลาสร้างและแก้ไข

## Backend API ที่ต้องทำ

| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | `/api/customers` | แสดงลูกค้าทั้งหมด |
| GET | `/api/customers/:id` | แสดงลูกค้ารายบุคคล |
| POST | `/api/customers` | เพิ่มลูกค้า |
| PUT | `/api/customers/:id` | แก้ไขข้อมูลลูกค้า |
| DELETE | `/api/customers/:id` | ลบลูกค้า |
| GET | `/api/customers/search?q=สม` | ค้นหาบางส่วนของชื่อหรือนามสกุล |
| GET | `/api/customers/nearby?latitude=16.245&longitude=103.25&radiusKm=1` | ค้นหาในรัศมี 1 กม. |

### Validation

- ชื่อและนามสกุลต้องไม่ว่าง
- เบอร์โทรต้องมีรูปแบบถูกต้อง
- latitude อยู่ระหว่าง -90 ถึง 90
- longitude อยู่ระหว่าง -180 ถึง 180
- ต้องไม่ลบลูกค้าที่มีออเดอร์อยู่ โดยไม่กำหนดกฎรองรับ
- การค้นหาระยะทางต้องใช้พิกัด ไม่ใช่ค้นจากข้อความที่อยู่

## Frontend ที่ต้องทำ

1. สร้าง `CustomerService` สำหรับเรียก API
2. สร้างหน้าแสดงรายการลูกค้า
3. สร้างฟอร์มเพิ่มและแก้ไขลูกค้า
4. เพิ่มปุ่มลบพร้อมกล่องยืนยัน
5. เพิ่มช่องค้นหาชื่อ/นามสกุล
6. แสดงพิกัดลูกค้าบน Leaflet map
7. เพิ่มช่องพิกัดและปุ่มค้นหาลูกค้าในรัศมี 1 กิโลเมตร
8. รองรับ loading, empty state และ error state
