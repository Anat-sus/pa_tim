# งานที่ 4: ระบบสำหรับไรเดอร์

## ผู้รับผิดชอบ

สมาชิกคนที่ 4

## เป้าหมาย

สร้าง Rider Portal สำหรับมือถือ ให้ไรเดอร์กรอกรหัสใบงาน ดูจำนวนกล่องรวม ลำดับจุดส่ง และเปิด Google Maps ไปยังลูกค้าแต่ละจุดได้ทันที

## ข้อมูลใบงาน

- `jobId` หรือ `deliveryBatchId`: รหัสใบงาน
- `riderName`: ชื่อไรเดอร์
- `pickupLocation`: พิกัดร้าน
- `totalBoxes`: จำนวนกล่องรวม
- `stops`: ลำดับจุดส่ง
- `estimatedMinutes`: เวลาที่คาดว่าจะใช้
- `status`: สถานะใบงาน

ข้อมูลแต่ละจุดส่งควรมี:

- ลำดับจุดส่ง
- ชื่อลูกค้า
- จำนวนกล่อง
- เบอร์โทรศัพท์
- ที่อยู่
- latitude/longitude
- สถานะการส่ง

## API ที่ต้องใช้

| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | `/api/delivery-batches/:jobId` | เรียกดูใบงานของไรเดอร์ |
| PATCH | `/api/delivery-batches/:jobId/stops/:stopId` | อัปเดตสถานะจุดส่ง |
| GET | `/api/delivery-batches/:jobId/navigation` | รับลำดับจุดส่งและพิกัด |

หากยังไม่มีตาราง `delivery_batches` ในช่วงแรก สามารถ mock response จากผลลัพธ์การคำนวณเส้นทางได้ แต่ต้องกำหนดรูปแบบข้อมูลให้ตรงกันเพื่อเปลี่ยนไปใช้ API จริงภายหลัง

## ลำดับการทำงานของหน้าไรเดอร์

1. เปิดหน้า Rider Portal บนมือถือ
2. กรอก Job ID หรือ Order Batch ID
3. กดค้นหา
4. แสดงชื่อใบงาน จำนวนกล่องรวม และเวลาประมาณการ
5. แสดงรายการจุดส่งเรียงตามลำดับ เช่น จุดที่ 1, จุดที่ 2 และจุดที่ 3
6. กดปุ่ม **นำทาง** เพื่อเปิด Google Maps
7. เมื่อส่งเสร็จให้เปลี่ยนสถานะจุดส่งเป็น `delivered`
8. แสดงสถานะเมื่อส่งครบทุกจุด

## การสร้างลิงก์ Google Maps

ใช้ latitude และ longitude ของจุดส่ง:

```typescript
const mapsUrl =
  `https://www.google.com/maps/dir/?api=1` +
  `&destination=${stop.latitude},${stop.longitude}`;
```

ปุ่มนำทางควรเป็นปุ่มที่เห็นชัดบนมือถือ และเปิดด้วย `target="_blank"` หรือ `window.open()` ตามรูปแบบของแอป

## หน้าจอที่ต้องทำ

- ช่องกรอก Job ID
- สถานะกำลังค้นหาและข้อความเมื่อไม่พบงาน
- การ์ดสรุปจำนวนกล่องและเวลา
- รายการจุดส่งแบบ step-by-step
- ปุ่มนำทางของแต่ละจุด
- ปุ่มหรือ control สำหรับเปลี่ยนสถานะการส่ง
- หน้าสรุปเมื่อส่งครบทุกจุด

## Responsive และการทดสอบ

- ออกแบบ mobile-first และใช้งานด้วยมือเดียวได้
- ปุ่มต้องมีขนาดกดง่ายและไม่ชิดกันเกินไป
- ทดสอบ Job ID ที่มีข้อมูล, ไม่พบข้อมูล และ API ล้มเหลว
- ทดสอบลิงก์ Google Maps บนมือถือและ desktop
- ทดสอบว่าลำดับจุดส่งตรงกับผลการคำนวณเส้นทาง
